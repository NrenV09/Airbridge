Zero-Backend WebRTC Internet Proxy

Share internet access from an online computer to an offline phone or laptop using a direct, local P2P WebRTC DataChannel. Initial signaling is exchanged completely offline via QR codes.

Host Gateway (Online)

Choose this on the computer with an active Internet connection (Wi-Fi, Ethernet, or 5G/4G).

  • Generates compressed SDP Offer QR Code
  • Scans Client's Answer QR to bind the P2P tunnel
  • Executes web requests and streams chunked responses

Client Node (Offline)

Choose this on the phone, tablet, or laptop connected to the local Wi-Fi or Hotspot without internet.

  • Scans the Host's Offer QR code with device camera
  • Generates compressed SDP Answer QR code
  • In-app HTTP browser to fetch web pages, APIs, and media
